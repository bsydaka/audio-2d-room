# audio-2d-room

## Run the room planner

This Java program starts a small web server that serves the room planner to a browser. Modern browsers do not run Java applets, so the interactive editor is served as a web page by the Java program.


Requires JDK 17 or newer. From this directory, run:

```sh
java audio-2d-room.java
```
